# 📁 Assets Directory Guide

This folder contains subdirectories for custom assets:
- `images/`: Drop your custom Polaroid photos or memories here. (The site automatically generates high-aesthetic illustration placeholders so it looks gorgeous out of the box!)
- `music/`: Drop custom background MP3 files here if you wish to override the built-in Web Audio API synthesized romantic multi-instrument symphony.
- `icons/`: Custom SVG icons and emblems.
- `fonts/`: Local font files (if not loading from Google Fonts CDN).
